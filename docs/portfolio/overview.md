# Redira Portfolio Overview

## Summary

Redira is a production-oriented URL shortening platform designed to demonstrate real-world backend engineering practices.

The project focuses on building scalable systems rather than a simple CRUD application.

---

# Engineering Areas Demonstrated

## Backend Engineering

- REST API development
- Service architecture
- Authentication
- Database interaction


## Performance Engineering

- Redis caching
- Efficient redirects
- Rate limiting


## Reliability Engineering

- Monitoring
- Metrics
- Testing
- Incident response documentation


## Production Engineering

- Docker deployment
- CI/CD practices
- Environment management
- Infrastructure documentation

---

# Project Goal

Build a system similar to production services used by companies handling large amounts of traffic and user-generated content.
