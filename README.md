# Redira

> A production-grade URL shortener built for speed, reliability, and scale.

Redira is a modern URL shortening platform built to demonstrate production-quality software engineering. It focuses on scalable backend architecture, clean code, testing, observability, security, and deployment.

## Tech Stack

### Backend
- Go
- Gin
- PostgreSQL
- Redis
- sqlc

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- TanStack Query
- shadcn/ui

### Infrastructure
- Docker
- Docker Compose
- GitHub Actions

### Monitoring
- Prometheus
- Grafana
- OpenTelemetry
